:hover

Hover over this link

The :hover pseudo-class applies styles when the mouse is placed over an element.

:focus

The :focus pseudo-class applies styles when an element receives keyboard or mouse focus.

:active

The :active pseudo-class applies styles while an element is being activated or clicked.
